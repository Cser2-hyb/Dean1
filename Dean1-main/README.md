# Event Equipment Rental & Logistics

Python console application for managing event equipment and rental orders.

## How to run

```bash
python main.py
```

## Main folders

- `models/`: OOP classes such as `Equipment` and `Rental`.
- `services/`: business logic for equipment, rental, and data analysis features.
- `storage/`: CSV/Text data files and file handling code.
- `utils/`: helper functions for validation and time processing.
- `docs/`: report, diagrams, flowchart, and presentation files.

## Assignment focus

- OOP with private attributes and property decorators.
- Modular programming with multiple `.py` files.
- CSV/Text data persistence.
- Console-based menu.
- Exception handling with `try-except`.
